# Iowa Agrivoltaics Dual-Revenue Estimator
single page site to calculate revenue from implementing a solar lease alongside crops

index.html    page markup (open directly in a browser, no server needed)
styles.css    all styling, light and dark themes
app.js        ISU 2026 county data, Solargis PVOUT table, light model, layout generator, calculator
iowa_pvout.json, county_pvout.py   how the PVOUT table was built from the Solargis GeoTIFF
Fonts load from Google Fonts; the page falls back to system fonts offline.

Credits: PVOUT, Global Solar Atlas, (c) 2019 Solargis, CC BY 4.0. ISU Extension Ag Decision Maker C2-10 and A1-20 (2026).
